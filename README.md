# ineed-legal

Public-facing legal pages for **I Need**, the iOS app.

Live at <https://magnusjune.github.io/ineed-legal/> via GitHub Pages, served
from `index.html` on `main`. Editing that file and pushing updates the live
page; there is no build step.

The privacy policy describes what the app actually does — on-device speech
transcription and interpretation, storage in the user's own iCloud, no
analytics, no third-party SDKs, no server. Keep it in step with the app's
`PrivacyInfo.xcprivacy` and the App Privacy answers in App Store Connect; if
those three disagree, App Review will notice.

This repository is public by design. It holds published legal text only — no
source, no identifiers, no configuration.
